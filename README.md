# CS-250-Portfolio
Portfolio showcasing Agile and Scrum practices from CS 250 at SNHU.

## Sprint Review and Retrospective

This repository contains my Sprint Review and Retrospective from CS 250. Throughout this course, I explored Agile and Scrum methodologies and learned how software development teams collaborate to deliver functional products while adapting to changing requirements. The SNHU Travel project provided an opportunity to understand user stories, team responsibilities, testing, and continuous improvement.

## Reflection

### How do I interpret user needs and implement them into a program? How does creating user stories help with this?

I interpret user needs by identifying what users expect from a program and determining how those expectations can be translated into functional requirements. Creating user stories helps organize these needs by describing features from the user's perspective. Throughout the SNHU Travel project, I learned how user stories guide development, establish acceptance criteria, and help ensure that the final product meets user expectations.

### How do I approach developing programs? What Agile processes do I hope to incorporate into my future development work?

When developing programs, I prefer breaking larger projects into smaller, manageable tasks while allowing opportunities for testing and improvement. Agile practices such as Sprint Planning, Daily Scrums, Sprint Reviews, and Retrospectives help maintain organization and encourage continuous feedback. The SNHU Travel project demonstrated the importance of adapting to changing requirements, including the shift toward wellness and detox destinations. I hope to incorporate these Agile practices into future projects to improve efficiency, flexibility, and software quality.

### What does it mean to be a good team member in software development?

Being a good team member in software development means communicating effectively, taking responsibility for assigned tasks, and supporting others throughout the development process. It also requires being open to feedback, addressing challenges collaboratively, and understanding how individual responsibilities contribute to the team's overall success. This course taught me that successful software development depends not only on technical abilities but also on teamwork, adaptability, and a shared commitment to delivering quality software.
